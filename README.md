# Nimbus releases

Downloads for [Nimbus](https://nimbus.stevcodes.com), a macOS system cleaner.

- **Install:** download `Nimbus.dmg` from the [latest release](https://github.com/stevhens/nimbus-releases/releases/latest), open it and drag Nimbus to Applications. Builds are signed with Developer ID and notarized by Apple.
- **Updates:** Nimbus updates itself. The `updates` pre-release holds the archives it downloads; you don't need them to install.

The source code is not in this repository.
